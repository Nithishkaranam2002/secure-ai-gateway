What it does

Four capabilities, one request path. Each one exists because of a specific way AI systems leak data or get abused.

1

Strict tool validation

Agents send malformed requests. Every tool argument is checked against a schema before anything runs, so a negative refund is refused rather than paid.

2

Tool level access control

Each caller carries a role. Privileged tools are refused before the request reaches the server, so an agent that has been tricked cannot reach them.

3

Live PII redaction

Emails, card numbers and social security numbers are removed while the answer is still streaming, even when a value is split across two chunks.

4

Limits and failover

Each customer gets a token budget on a sliding window. If the main provider is slow or refusing, traffic moves to a backup without the user noticing.
